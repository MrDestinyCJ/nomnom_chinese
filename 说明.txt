========================================
  《美味银河》简体中文汉化补丁 v1.0
  Nom Nom Galaxy Chinese Patch
========================================

【补丁内容】
  · 全量汉化：游戏 2164 条文本，汉化 2154 条
    （菜单/教程/挑战/联机/成就/汤品名/剧情对话全都有）
  · 补字库：补入 975 个汉字字形，不会出现方块
  · 修复 PC 版切中文就整屏没字的问题
  · 选项菜单里可以直接选「简体中文」

【安装方法】—— 三步
  1. 把本压缩包解压到任意目录（路径别带奇怪符号就行）
  2. 双击运行「安装汉化.bat」
     看到「安装完成！直接启动游戏即为简体中文。」就成功了
  3. 启动游戏，开玩

  ※ 如果游戏不在默认目录（D:\SteamLibrary\steamapps\common\NomNomGalaxy），
    在本目录新建一个 game_path.txt，里面写一行你的游戏安装路径。

【卸载还原】
  双击「卸载还原.bat」，一键回到英文原版。

【常见问题】
  Q：Steam 更新了游戏，或者我点了「验证游戏文件完整性」，汉化不见了？
  A：正常，这两个操作都会拿原版覆盖。备份还在，
     重新双击一次「安装汉化.bat」就恢复汉化了。

  Q：选项里的语言项为什么显示「简体中文」，但有人说是西班牙语？
  A：官方把中文从语言菜单里屏蔽了，补丁借用「西班牙语」的位置放中文，
     菜单名字已经改成「简体中文」，正常用没影响。

  Q：不小心切成别的语言了怎么切回来？
  A：选项 → Language → 选「简体中文」那一项。

  Q：会影响存档 / 成就 / 联机吗？
  A：不会。只替换文本和字体资源，不动存档结构。

  Q：提示找不到 Python？
  A：需要装 Python 3（官网免费下，安装时勾选 Add to PATH）。
     如果电脑上装了 DSH / Claude Code 之类的运行环境，一般已经自带。

  Q：杀毒软件报毒？
  A：补丁就是几个 .py 脚本 + .bat 启动器，会读写游戏目录下的
     data.pkdwin，可能被误报。不放心可以右键用记事本打开脚本自己看。

【Windows 提示「可能对你的计算机有害」怎么办？】
  这是 Windows 对 .bat / .cmd 脚本的**通用警告**，不是杀毒软件查出病毒——
  任何没有数字签名的脚本从网上下载后都会弹这个提示。
  本补丁的代码就是几个纯文本脚本，右键用记事本就能打开查看，
  它只做两件事：① 读写游戏目录下的 data.pkdwin ② 改存档里的语言字段。

  四种解决办法，任选其一：
  ① 弹窗里点「更多信息」→「仍要运行」
  ② 解压前先解锁：右键压缩包 → 属性 → 勾选底部「解除锁定」→ 确定，再解压
  ③ 解压后批量解锁（推荐）：
     在补丁文件夹空白处按住 Shift + 右键 →「在此处打开 PowerShell 窗口」，执行：
       Get-ChildItem -Recurse | Unblock-File
  ④ 完全不想碰 .bat：在补丁目录打开命令行，直接执行
       python install.py

  如果不放心，可以先核对下面的校验值（用 certutil 或任何哈希工具算），
  确认文件和发布页一致再运行。
